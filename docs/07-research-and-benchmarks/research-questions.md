## 1. Core Research Questions (RQs)

* **RQ1 (Reconstruction Quality):** Can multimodal cross-source evidence reconstruct handoff context with higher completeness and precision than document-only LLM summaries?
* **RQ2 (Temporal Reasoning):** Does explicit temporal graph modeling reduce stale/deprecated architectural claims compared to standard vector RAG?
* **RQ3 (Hidden-Work Detection):** Can cross-source discrepancy rules detect unfinished work that single-source task trackers fail to report?
* **RQ4 (Decision Lineage):** Does capturing historical rejected alternatives reduce false assumptions by incoming project owners?
* **RQ5 (Diagram Multimodality):** Does computer vision extraction of architecture diagrams improve system dependency recall?
